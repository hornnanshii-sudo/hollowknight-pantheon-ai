# 格鲁兹之母纯躲避课程

本轮新模型从零初始化；旧技能权重保留。仅12种移动×跳跃/冲刺动作，攻击、施法、回血禁用，C# mode dodge再检查输入位白名单。每局确认Boss未扣血；检测被动攻击护符并失败退出，不偷偷修改解锁或无敌。

观测200维：26维技能/运动状态+双方主Collider2D的AABB中心与半径、朝向、Boss Control FSM阶段的16桶稳定哈希编码，共50维×4帧。AABB仅粗略碰撞范围，非精确危险判定；阶段哈希可能碰撞，尚无投射物或所有子碰撞体。Boss是格鲁兹之母。

五段每20000步，共100000步。训练无伤目标依次10/20/40/80/120秒；受伤即结束，逐渐延长连续躲避。奖励：每无伤游戏秒+0.1，每损失1血-5，达成目标额外+5×目标/120。没有距离、按键、攻击奖励。

每段正常速度真实游戏检验1局，始终要求120秒无伤；仅1局不能证明稳定成功率。受伤即失败并退出，成功达到120秒后截断。游戏时间上限120秒，墙钟看门狗150秒，单次桥接socket35秒/主线程30秒。无伤持续时间、血量、损失血量、意外攻击数量分别记录；不称为Boss击杀胜率。

后续再训练普攻反击、黑砸和安全回血。桥接新增bit8=focus（256），已有down+quickCast可黑砸，但本轮白名单不允许这些位。回血输入已提供，尚未专项实战验证。不要直接将12动作/200维的新模型作为45动作/104维旧技能模型加载，后续课程需显式适配策略输出与观测。

启动：`.venv/Scripts/python.exe dodge_pipeline.py`；结果目录artifacts/dodge-100k-pipeline。权重和媒体留本地，源码上传GitHub。训练在PPO更新期间游戏仍运行，尚未严格锁步。
