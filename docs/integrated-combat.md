# 六帧综合战斗课程

只训练格鲁兹之母。综合战斗模型最初从零训练；本次显式迁移已完成参数更新的3000步检查点，不加载旧纯防御模型。新接口为220维结构化状态×6帧=1320维、25动作，PPO演员和价值网络各128×128。按0.08游戏秒连续采样，最旧到最新帧相隔0.40秒；不是六张屏幕截图，也不是循环网络。

新增Boss剩余血量及有效标志、聚焦状态/持续时间/魂消耗进度、施法及后摇、攻击与冲刺锁定、暗影冲刺能力。保留地形射线、可见边界、危险碰撞框、速度、招式、冷却与无敌状态。四帧迁移把旧四帧权重映射到最近四帧，新增加的两帧和11个状态初始权重为零；测试验证迁移瞬间相同旧输入的动作概率和价值相同。维度改变后优化器重新初始化，后续正常恢复保留新优化器。恢复不复原Unity随机数、当时战斗或未完成的采样批次，不宣称逐位可重复。

总累计上限300000步，已完成3000步计入预算。每累计10000步冻结参数评测30局，每局最多120游戏秒。基础开放移动、跳跃、冲刺及普攻；混合和巩固开放黑砸、回血。正常30局评测两轮连续胜率≥90%、胜局平均掉血≤2、无离屏/墙钟保护超时才满足战斗门槛。基础和混合分别最多100000步；预算耗尽即使未达标也升级，记录budget_unmastered，剩余预算给巩固。

混合训练70%正常9血0魂、15%回血练习6血99魂、15%黑砸练习9血66魂；巩固90%正常、10%两种专项。专项仅设置初始资源，途中不补血补魂。所有正式战斗评测9血0魂。混合及巩固每两次检验额外各10局回血和黑砸专项，每局最多20秒；专项成绩独立呈现，不算正常胜率。最近各30局专项≥80%才认可这两项技能：回血必须实际完成聚焦回血且聚焦期间及完成后0.5秒未受伤；黑砸必须实际造成黑砸伤害且施放窗口未受伤。混合提前升级需同时满足战斗和技能门槛；预算升级允许技能未掌握，但必须明确报告。

伤害计数通过HealthManager.TakeDamage事件按攻击类型和来源记录，区分普攻、法术、黑砸；黑砸属于法术子集，不能将两者相加。实际受伤和回血通过PlayerData.TakeHealth/AddHealth计数，避免一次采样内先受伤后回血被血量净差抵消。黑砸来源/施法状态分类和施放后受伤仍存在归因限制；只有真实游戏验证的来源可作为证据。暗影冲刺后0.5秒受伤指标是关联，不证明冲刺导致伤害。

主奖励数值保持integrated-combat-v1：真实削减完整Boss血条累计最多+10（血量变化与伤害事件双重验证）；每掉一格血−1；死亡−3；每游戏秒−0.01；120秒未击杀−2；击杀+10、终局血量最高+5、全程零受伤再+5；完全离屏−12。无必要实际冲刺仅普通−0.003/暗影−0.005，接近/临近危险豁免。无位置、存活、挥刀、施法、回血按钮、估计躲避的持续正奖励。回血通过生存与终局血量间接获益。受伤事件统计纠正会影响存在回血回合的扣分，应与旧记录区分。

训练、常规检验、最终确认使用不重叠的合法走路/等待开局组合，不传送角色。常规检验6种开局重复覆盖30局；最终确认6种未参与模型选择的开局覆盖100局。Unity随机数尚未受Python种子控制，不能声称局数对应完全独立随机样本；95%二项区间不刻画全部场景泛化风险。

每阶段保存正常评测最好的模型，按胜率、无伤率、胜局掉血、胜局时间排序。继续训练始终从最新检查点，不能从best回退重放预算。300000步结束后，用最佳full模型进行100局正常资源最终确认，然后complete并停止监测；评测动作不计入训练步数。最终胜率≥95%、胜局掉血≤1只是参考目标，未达标不扩预算。

状态为artifacts/integrated-combat-300k-pipeline/status.json，支持显式--resume。检查点原子替换，只保存完成优化器更新的边界；采样失败不能保存带未学习步数的部分模型。训练及常规评测子进程至多两次重试并保留错误日志，其他故障明确failed，不无限重启。游戏每步严格四物理帧，采样外暂停；玩家必须Dynamic、无无限空跳，无被动伤害护符。边界、步长或动作掩码不符合约定立即报错，不放宽断言继续制造数据。

验证包括六帧迁移概率/价值一致、掩码在各任务正确、关键状态可见、开局集合不重叠、奖励漏洞检查、技能门槛、best选择及预算未达标仍走完三阶段。另做真实游戏开局、步长、回血和黑砸事件检查。接口通过不能证明训练效果，须等待正常30局报告。
