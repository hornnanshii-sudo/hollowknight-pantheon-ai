# 六帧综合战斗课程

仅训练格鲁兹之母，累计预算300000步，每累计10000步冻结参数进行10局实战检验，每局最多120游戏秒。动作升级时保留已完成10000步模型的状态编码器和价值网络，重新初始化不兼容的动作输出和优化器；旧25动作的12局中断检验归档，不算完整检验，不参与升级和模型选择。不加载旧纯防御模型。

## 观测和动作

结构化状态265维×6帧=1590维。PPO演员和价值网络各128×128，442900个参数。每动作严格推进4个物理帧，即0.08游戏秒，采样外暂停；历史跨度0.40秒。支持2物理帧模式并通过输入诊断，但当前训练仍采用4帧。不是六张截图，也不是循环记忆。

观测包括Boss状态/血量/速度，地形射线、视野边界、最近危险碰撞框，角色冷却、无敌、法术/聚焦状态、真实资源和蓄力进度，原生能力合法性及上次各动作头选择。为迁移编码器，保留旧输入布局；旧离散动作槽置零，新的组合历史有独立位置。迁移不复原Unity随机数、当时战斗或未完成采样，不宣称逐位可重复。

六个条件动作头依次选择：施法/聚焦(5)、横向移动(3)、上下方向(3)、跳跃(3)、攻击(3)、冲刺(2)，总计19个输出logit，并非19个固定动作。前一个动作选择约束后面的合法组合，采样和PPO训练使用相同条件概率。普通攻击可与移动及空中上下斩组合；跳跃可保持、释放、重新按下。原生游戏决定二段跳、墙跳、冲刺冷却及暗影免伤，代码不直接修改位置、速度或技能次数。

攻击可点按、持续蓄力、释放：剑技由游戏原生FSM触发大斩、旋风斩、冲刺斩。持续蓄力允许首刀后摇期间继续持键，不能因为暂不可再次攻击而强制释放。只有已持有且未过度保持的蓄力可跨步延续。横向黑波、向上黑吼、向下黑砸具有强制匹配方向与灵魂门槛；回血必须持续聚焦，释放或移动可取消。初始按下/持续按住/松开区别明确；“跳跃同时下斩”在地面可能仍为平砍，空中下斩需先实际离地。

基础阶段允许移动、跳跃、冲刺、普通攻击；混合和巩固开放上述法术、回血与蓄力剑技。实现输入接口不等于模型已学会使用全部技能。

## 奖励与消极行为

版本integrated-combat-v2-inactivity保留真实伤害与血量主奖励：削减完整Boss血条累计最多+10；掉血−1/格；死亡−3；时间−0.01/游戏秒；120秒未击杀−2；击杀+10、终局血量最高+5、全程零受伤额外+5；完全离屏−12。无必要实际冲刺普通−0.003/暗影−0.005，接近/临近危险豁免。不为位置、存活、挥刀、施法、回血按钮或估计躲避持续发正奖励。

新增消极成本：最近2秒横纵位置变化均小于0.35，且至少2.5秒没有实际造成伤害或回血，扣0.04/秒；连续8秒没有上述有效进展，即使一直移动也扣0.02/秒。正常聚焦、合理蓄力、施法后摇、剑技、受伤硬直及临近威胁可短时豁免，每次真实有效进展后豁免累计最多3秒。两种成本合计上限0.06/秒，不能靠反复切换按键刷新无限豁免。持续有效输出的站桩不会因位置未变扣分，以免训练出无意义乱跑；该规则不保证杜绝所有有效的角落打法，须通过不同开局与后续Boss检验泛化。

实际掉血/回血采用PlayerData.TakeHealth/AddHealth事件，避免同一步先受伤后回血相互抵消。Boss伤害采用HealthManager.TakeDamage事件并限制过量伤害，保留来源对象层级用于分类；法术、黑砸及剑技子集不能与总伤害重复相加。冲刺后受伤和技能窗口受伤只是关联，不能证明因果。黑砸免伤由原生游戏处理，代码不授予无敌。

## 课程、检验与停止

连续两轮正常10局检验胜率≥90%、胜局平均掉血≤2、无离屏/墙钟保护超时满足战斗升级门槛。基础和混合各最多100000步；预算耗尽未达标也升级，记录budget_unmastered，剩余给巩固。10局样本小，升级是工程规则，报告Wilson95%区间，不宣称已证明稳定90%胜率。

混合训练70%正常9血0魂、15%回血6血99魂、15%黑砸9血66魂；巩固90%正常、10%两种资源辅助专项。专项只设置初始资源，途中不补血补魂。正式检验全部9血0魂。混合及巩固每两次检验额外各10局回血和黑砸专项，每局最多20秒，独立报告，不能算正常胜率。最近各30局专项≥80%才认可这两项技能；回血须实际完成且聚焦期间/完成后0.5秒未受伤，黑砸须实际造成对应伤害且施放窗口未受伤，均不得死亡/离屏/看门狗超时。混合提前升级需同时满足技能门槛，预算升级须明确技能未掌握。

训练、常规检验、最终确认使用互不重叠的合法走路/等待开局组合，不传送。常规与最终各10局，覆盖各自6种组合并重复部分组合；Unity随机数尚未受Python种子控制，不能当作完全独立随机样本。每阶段保留正常检验最佳模型，按胜率、无伤率、胜局掉血和时间排序；继续训练始终从最新检查点，不回退best重放预算。300000步结束后，以最佳full模型在未参与选择的开局做10局最终确认，然后结束并停用监测。检验动作不计入训练步数。

状态位于artifacts/integrated-combat-300k-pipeline/status.json，使用integrated_combat_pipeline.py --resume。只保存完成优化器更新的边界，检查点原子替换；部分采样失败不冒充已学步数。训练和常规检验最多两次重试并保留错误，其他故障明确failed。角色必须Dynamic、无无限空跳，无被动伤害护符；步长、边界、动作掩码不符合契约立即报错。

验证包括条件动作采样与训练概率一致、蓄力冷却持续按键、资源/阶段掩码、消极行为豁免不能无限刷新、正常10局开局契约、阶段预算升级以及真实游戏施法、回血取消、剑技释放和2/4帧同步。接口验收与训练成绩分开，等待新10局正式报告后评价模型。

同步故障修复：物理步达到目标时由FixedUpdate立即暂停；脉冲输入先在一个物理步释放，再暂停等待Update按下，避免等待渲染帧期间额外推进。同步时间采用双精度累加实际fixedDeltaTime，避免长时间运行后单精度fixedTime输出舍入造成0.079/0.08误差。Python仍严格要求2/4个物理步及对应游戏时间，未通过放宽容差隐藏故障。
