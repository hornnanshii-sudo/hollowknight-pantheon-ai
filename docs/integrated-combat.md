# 从零综合战斗课程

只训练格鲁兹之母。从随机PPO权重开始，不能加载旧防御或旧课程模型；正常恢复仅接受integrated-combat-v1检查点。836维四帧观测、25个真实输入动作、128×128网络保持一致；绝对位置换为视野相对位置。每步四物理帧约0.08游戏秒。

总上限300000步，每10000步冻结模型进行30局独立真实游戏评测，单局最多120秒。基础阶段允许移动、跳跃、冲刺及普攻；技能混合和巩固开放黑砸、回血。连续两次30局胜率≥90%、胜局平均掉血≤2且无离屏/超时可提前升级；基础和混合各最多100000步，未达标也升级，剩余预算用于巩固。此门槛衡量整场表现，不能证明已经掌握黑砸或回血。完整巩固最终报告以胜率≥95%及胜局掉血≤1为参考目标，不无限扩预算。

技能混合：70%正常满血零魂战斗，约15%缺血6/99魂回血条件，约15%满血66魂黑砸条件；巩固约90%正常战斗，10%专项。专项只设置回合初始资源，战斗中不会补魂补血。所有正式评测正常满血零魂开局。评测中基础仅普攻，其余开放技能，因此跨阶段成绩需注明动作集合。

主奖励统一：实际削减完整Boss血条累计最多+10（需要血量变化及真实伤害计数相互验证）；每损失一格血−1；死亡额外−3；每游戏秒−0.01；超时未击杀−2；击杀+10、剩余血量比例最高+5、全程无伤额外+5；完全离屏异常−12，避免利用提前终止逃避成本。不奖励挥刀、施法、回血按钮或估计躲避；不持续奖励存活/贴近位置，也不按逃跑方向惩罚。回血通过降低死亡风险和提高终局血量产生收益。

无必要实际冲刺仅普通−0.003、暗影−0.005，接近/避险豁免；这比旧费用降低10倍，避免辅助成本支配动作。分类及冲刺后0.5秒内受伤仍只是估计关联。接战、远离、角落、技能尝试和回血指标用于诊断，不作为完成任务的硬性位置约束。估计躲避奖励被移除，当前avoidances字段为兼容旧日志保留的零值，不表示没有发生躲避。

单测验证不输出的等待/逃远回合没有正奖励、实际伤害需要双重数据、过量击杀伤害截断、无伤终局优于有伤，以及整套调度在未达标情况下仍准确走完30次检验和三个阶段。另运行真实游戏接口检查与固定策略基线。单测不能证明实际学习效果。
