# 游戏环境接口草案

这是一份待实现的接口设计，不代表已经存在游戏插件。

## 观测
玩家位置/速度、朝向、血量/灵魂、落地与动作状态、技能冷却；敌人和危险实体的相对位置、速度、碰撞框与类型；场地边界、平台、Boss 阶段。实体数组需要有效性掩码，模型不得读取未来动作或随机数。

## 动作
方向、跳跃、冲刺、攻击、法术、治疗的按键状态。按键可以跨步骤保持；重置、断连和停止时释放全部输入。

## 步进与重置
`step(action)` 在指定数量的游戏物理步后返回 observation、reward、terminated、truncated 和诊断信息。不能仅依靠 Python sleep 作为游戏时钟。

`reset(options)` 支持 Boss/场地/阶段与起始资源；确认场景加载、玩家存活、敌人初始化和残留弹幕清理后才返回。训练模式允许受控重置；评测模式禁止中途重置和状态修改。

## 奖励与评测
命中、受伤、获胜、死亡事件以游戏事件计数计算，防止轮询丢失。伤害奖励按敌人最大血量归一化；辅助奖励需通过独立胜率验证。截断和死亡分开处理。战斗间保留实际资源。
