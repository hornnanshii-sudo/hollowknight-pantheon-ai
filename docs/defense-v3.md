# 连续防御训练 v3

从随机权重开始，不加载旧模型。观测保持704维、四帧，18个移动/跳跃/冲刺动作，PPO网络保持128×128。纯防御禁止攻击、施法、回血。

总计100000步，五段各20000步；每段30局独立120秒真实游戏评测。不再采用10秒起步课程。受伤继续，死亡或120秒结束；完全离屏视为异常失败，600秒墙钟超时截断。

奖励：存活每秒+0.02，每损失一格血−5，死亡额外−5，估计有效躲避+0.2且单局上限+5，危险冲刺后实际受伤额外−2。120秒无伤+10，有伤存活+2×剩余血量/9。安全接战使用小额折扣势能差，不持续奖励占据位置。威胁存在时距离目标让位于安全。

躲避需要动作前预测0.35秒内碰撞、移动后观察0.5秒未掉血、原碰撞框仍可观测且无预计碰撞、落点没有伤害框重叠。同一碰撞框和Boss动作事件只支付一次。受伤无敌不奖励，暗影冲刺无敌允许参与判定。威胁消失不直接视为成功，避免奖励无法验证的事件。

冲刺必须被实际触发，使用20单位/秒、约0.15秒冲刺的近似轨迹和0.3秒预测窗口。暗影冲刺可穿越的一般伤害在早期无敌窗口内排除；随后0.5秒内真实掉血才追加一次惩罚。该方法只能估计关联，不能证明冲刺是伤害原因；速度、无敌窗口和多威胁情况下均有误差，应检查实战日志。Boss阶段事件不是精确攻击身份。

评测区分120秒存活率和无伤率，均报告Wilson 95%区间。另记录血量、首次受伤时间、每分钟掉血、估计躲避、危险冲刺后受伤、接战比例、远离时间、离屏、游戏dt及奖励分项。暂不具备攻击能力，存活不等于击败Boss。
