# 单Boss问题总结与连续课程

范围仅格鲁兹之母，不执行多Boss或连战。当前v3权重保留，统一输入输出后继续，优化器重建。四帧每帧209维，共836维；25动作，前18个移动/跳跃/冲刺与v3一致。新增魂量、黑砸状态、累计掉血、课程和上次技能动作。首次线性层按帧迁移旧176维权重，新列为零；动作输出前18行保留。后续切课不再改变维度。

遇到的问题：

1. 直接进场遗留Kinematic刚体，导致不合法上升：就绪时恢复Dynamic，检查真实落地。
2. 渲染卡顿导致一帧补多个物理帧：同步模式限制maximumDeltaTime，保持四物理帧断言；断言失败停止报错，不当成正常训练。
3. 生存奖励诱发逃角落、近身奖励诱发贴撞：采用小额接战势能差；有效躲避必须有可观测威胁、延迟无伤结算、单威胁去重和整局上限。仍属估计，不能证明因果。
4. 一滴血即结束限制连续学习：受伤继续，死亡/120秒结束，离屏和墙钟异常保护。
5. 只看平均回报无法判断技能：独立记录无伤、首次受伤、每分钟掉血、冲刺受伤、有效输出、回血、黑砸及其风险。
6. 部分rollout异常退出：保留实际已保存步数，剩余训练采用不超过1000且整除剩余量的rollout长度，不能将剩余预算向上取整。尚未保存的故障前采样不属于恢复后的累计计数。
7. 前置课程门槛可能阻塞后续能力：连续两次达标提前升级，阶段预算用尽强制升级，明确标为未掌握；不保证强制升级后已具备前置能力。

总预算仍为累计100000步，包含已完成13763步。第一万步检验已错过，迁移后立即补测；随后20000、30000……100000步各30局，120秒上限。最迟分配为防御到40000步、普攻到60000、黑砸到70000、回血到80000、完整战斗到100000。早升级腾出的预算留给后续任务。达到总预算后保存最终评测并停止，不无限运行。

门槛：防御120秒存活≥90%、每分钟掉血≤1、接战比例≥25%；普攻胜率≥90%、胜局掉血≤2；黑砸另要求至少80%已实际触发的黑砸在1秒窗口内有有效伤害且未受伤；回血胜率≥90%、每局平均恢复≥1格、1.5秒窗口内受伤的回血尝试比例≤10%；完整战斗胜率≥95%、胜局掉血≤1。至少30局、无离屏/超时，连续两轮达标。完整阶段不再升级。30局决策并不证明总体胜率，报告Wilson区间。

动作屏蔽同时用于PPO采样、训练log概率和确定性评测，不靠环境把非法技能改成等待。防御只允许前18动作；普攻开放三方向移动普攻；黑砸开放下施法；回血和完整开放持续集中回血。后续阶段随机20%训练回合复习旧任务，评测只测试当前任务。当前没有加入黑波、黑吼或剑技。

所有完整战斗评测从满血零魂正常开局；回血专项从6血99魂开始，这只是回合初始课程条件，并不在战斗中补资源。不能把回血专项成绩当成正常开局战绩。下一步应改进攻击窗口、回血机会的独立测试集，目前命中和安全性采用时间窗口代理指标，黑砸伤害也可能混入同一窗口的普攻伤害。

状态在artifacts/single-boss-100k-pipeline/status.json。故障修复后以single_boss_pipeline.py --resume恢复；不会自动无限重启故障。每个任务使用同一检查点继续，检查点评测不更新梯度，新的JSON报告才分析一次。升级理由区分mastery和budget_unmastered。


## 持续逃远修正

右上攀墙策略在前两局诊断中远离约25/63秒，接战仅25%左右。EngagedReward增加威胁过去1秒后、持续远离超过2秒的每秒0.04递增至0.12惩罚，远离高墙/天花板滞留超过2秒额外每秒0.08惩罚；对应时间不发存活奖励。Boss距离6单位以上的躲避结算不支付辅助奖励。正常近身跳跃和短暂撤退不受罚。

防御任务成功现要求120秒存活且近身比例≥35%、距离6以上的时间≤20%、远离高墙滞留≤5%；另报告原始120秒存活，不能将逃远存活当成达标防御。中断的旧奖励诊断保留，模型与步数不重置，从13763继续至20000再评测，预算与强制升级规则不变。


## 无必要冲刺成本

仅实际冲刺启动时计费，不按按键请求或持续物理帧计费。动作前0.4秒内预计碰撞或已接触有效伤害框时，视为避险用途，不收使用成本；动作前Boss表面距离大于5且本步距离减少超过0.2时，视为接近用途，不额外奖励冲刺。其余普通冲刺每次−0.03，暗影冲刺每次−0.05。危险冲刺后受伤的原惩罚仍保留，豁免使用成本不代表冲刺安全。

日志增加实际冲刺、估计避险/接近/无必要次数，以及冲刺后0.5秒内受伤次数；报告每分钟冲刺、无必要比例、后续受伤比例。分类和后续受伤只是估计关联，不能证明因果，不以冲刺次数越少为越好。保留权重和原预算，升级达标连续计数重置。
